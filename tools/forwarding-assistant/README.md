# 如如转运助手（Chrome MV3）

淘宝 / 天猫 / 拼多多浏览器订单与物流管理。**个人原型 v0.1，尚未在实际账号登录页面完成端到端验证。**

## 安装

1. 下载本目录文件并保留在同一个文件夹（不要只选择 ZIP）。
2. Chrome 打开 chrome://extensions，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选中本目录。
4. 打开淘宝、天猫或拼多多网页版的「我的订单 / 物流详情」页面，刷新后插件会尝试自动读取页面**可见的**订单和快递单号。
5. 点击拼图图标并固定「如如转运助手」。点「抓取当前页面」可手动重扫；点「管理全部」打开完整列表。

## 功能

- 按平台+订单号保存一个订单，内含多个商品、多个快递包裹。
- 逐个包裹复制运单号、标记已转运/撤销标记，备注和按商品名称关联包裹。
- 支持搜索、按平台/状态筛选，JSON 导入/导出，Excel 可读 CSV 导出。
- chrome.storage.sync 同账号跨电脑同步；chrome.storage.local 本地备份。
- 不采集账号密码、Cookies，不调用淘宝/拼多多的私有接口，不提交自动订单操作。

## 同步说明

Chrome 需使用**同一个 Google 账号**开启同步，且在另一台设备安装本插件。仅在不同电脑登录淘宝或拼多多不会同步插件记录。
Chrome Sync 有约 100 KB 总量 / 8 KB 单项 / 512 项的配额，适合个人中小规模清单；大批量建议定期导出 JSON。满额或写入失败时本地保留记录，界面会警告，允许重试。没有账号级云数据库，不保证登录淘宝账号自动恢复。

## 重要限制

- **仅抓取你打开并加载到网页中的可见 DOM 内容**；不在后台登录、遍历所有订单或绕过验证码/风控。分页、滚动加载的订单需要逐页打开。
- 淘宝/天猫与拼多多的新版页面、动态渲染、物流详情可能改变 DOM 结构，因此自动识别并不能保证成功；拼多多桌面端若不展示订单物流，需手工输入或 JSON 导入。
- 关联规则优先按明确订单号归并；一单多商品多包裹未提供可靠对应关系时，不自动猜测，建议在管理页面手动指定。
- 同时在多电脑离线修改同一订单可能发生最近写入覆盖；请避免并发改同一订单。
- 浏览器同步存储不适合身份证、地址、电话号码等敏感个人资料；请勿在备注录入这类数据。

## 源码结构

- manifest.json：权限及匹配域名。
- content.js：DOM 页面识别（只读）。
- background.js / storage.js：存储、合并与同步。
- popup.html / dashboard.html / app.js / style.css：界面、复制、筛选、导入导出。

发布 Chrome 商店前需要实际订单页面回归测试，并加上隐私声明与图标。此仓库中的开发代码不包含任何真实订单或账号数据。
